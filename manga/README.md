# تحديثات مصادر تطبيق ShaDo مانجا

يقرأ التطبيق `manga/remote.json` عند الضغط على «تحديث المصادر الآن»، دون تثبيت APK جديد.

- `v`: رقم النسخة (يُرفع مع كل تعديل).
- `homes`: `{ "id": "https://النطاق-الجديد" }` لتغيير رابط مصدر انتقل موقعه.
- `sources`: `[{ id, name, home, tpl, p:{...}, plugin:"plugins/x.js", sha256 }]` لإضافة مصدر أو تعديل مصدر مدمج.
- `off`: `[id]` لإخفاء مصدر معطّل.
- `engine` (اختياري): `{ version, files: { "kit.js": "sha256" } }` لاستبدال ملفات المحرك.
